# Results

One file per result: the statement, its hypotheses and scope, its status in the vocabulary of AGENTS.md (Theorem, Proposition, Counterexample, No-go theorem, Conjecture, conditional on a named hypothesis), where the proof is (a lemma and its numbered item, or the file itself), and who proved it (the identifiers of `ledger.pl`). A results file states; it does not prove, except for results whose proof is not in a lemma, which is then written out here.

This directory, `lemmas/` and `paper/` are the sources of every PDF in `docs/`; `paper/build_supplement.sh` refuses any other path.

For instance, along the Berger curve a change of radius changes both matching couplings at fixed Einstein coefficient. A block-spin step needs a blocking map at a specified background and an effective action for the retained variables. For a quadratic operator the eliminated sector contributes the Schur complement in result 13. Computing a projected spectrum alone leaves that term and, in a Gaussian path integral, the determinant of the eliminated sector to account for. The two routes therefore test different operations even when both use a length called a cutoff.

The plate 08 window uses one free, minimally coupled complex scalar below both circle pair thresholds and a fixed microscopic cutoff. The tree photon coupling weights its cut. The growing fixed-band dispersive contribution tests the further local matching needed for a perturbative real response. [Plate 08 dispersion](issues/26.md#fixed-band-spacelike-dispersion)
