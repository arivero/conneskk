# Along a gauge orbit the modulus of the link stays fixed for the covariant projection of the parent and for the finite data with the quadratic term, and grows at second order for the fixed compression and for the finite data with linear terms only

**Status.** Proposition (Proposition 19.3), a parallel with no identification. Proved by Claude Opus 5.5. Ledger row `l19_parent`.

**Setting.** The chiral interval at M = 0 with m = pi/(2l); the link of the fixed compression (lemma 13, Proposition 13.2; 13_fixed_compression_gauge_fluctuations.md), the link of the covariant projection (lemma 14, Theorem 3; 14_link_fixed_singular_values.md), and the two-point fluctuations of 19_fluctuations_two_point_data.md.

**Statement.**

1. With no real structure, the finite fluctuation is m(1 + phi_1), all of C, while the fixed compression of a gauge field gives only the line m + iB.
2. With pointwise reality, the parent C(I) is commutative with J f J^{-1} = conj(f), satisfies order one, and has A + J A J^{-1} = 0 for a scalar one-form, so the specified parent has no surviving self-adjoint scalar inner fluctuation, while the truncated data have the gauge-neutral radial parameter t.
3. With the reflection real structure, the parent satisfies order one, J_r D_{A_5} J_r^{-1} = D_{A_5 o R} with R the reflection, the symmetrized field A_5 + A_5 o R survives, and the fixed compression gives m + i B^s with B^s = 2B, the weight sin(pi x/l) being even about l/2.
4. Along a pure-gauge path the modulus of the link is constant for the covariant projection (lambda W_l^\\*, fixed singular value) and for the finite data with A_(2) (m); it is (m^2 + B^2)^{1/2} for the fixed compression and m(5 - 4 cos psi)^{1/2} for the finite data with J_r and linear terms only, both growing at second order.

*Scope.* A parallel, with no identification of variables: for constant unsymmetrized A_5 = a the transported link is m e^{ial} = m + i(pi a/2) + O(a^2), with Wilson phase al, against m + i(2a/pi) in the compression. Item 2 establishes neither a dynamical scalar field nor its action, and says nothing about parent fields in other models; compression is not multiplicative, so finite potentials have no canonical identification with parent potentials. The phase of a link depends on the frame, its modulus does not.

**Proof.** Lemma 19, Proposition 19.3; the proof is there, collecting lemma 14, Theorem 3, Corollary 19.2 and lemma 13, Proposition 13.2; for item 2, K (i E a) K^{-1} = -i E a for a real a.

**What it leaves open.** An exact statement relating a fluctuated parent and its truncation holds on gauge orbits by lemma 22, Corollary 22.6, and remains open for the nonunitary part (lemma 19, Reading).
