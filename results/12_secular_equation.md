# The boundary-Yukawa interval has the exact secular equation det(lambda^2 - A(lambda) X B(lambda) X^dagger) = 0 below the first poles, and for one massless flavour its spectrum (n pi +- arctan|X|)/l interpolates from types (a) + (b) to two copies of type (c)

**Status.** Theorem (Theorem 12.4 and Example 12.5). Proved by Claude Opus 5.5; checked by Claude Opus 5.5 against ODE shooting (scipy solve_ivp, rtol 1e-12; agreement to 6 digits) and by Terra 6.1 by hand, effort max: item 2 of Theorem 12.4 wrong as first stated on the common window and corrected, Example 12.5 correct with amendment (report appended to lemma 12). Ledger row `l12_secular`, depending on `l09_lightpair`. Theorem C of paper/towerless_intervals.tex. The one-flavour spectrum is equation (5.6) of Csaki-Grojean-Hubisz-Shirman-Terning (2004) (lemma 12, Literature).

**Setting.** D_X of 12_boundary_yukawa_index.md, with c_i^Q = -m_i^Q l and c_j^U = m_j^U l. For a field of mass m and lambda > 0, omega = (m^2 - lambda^2)^{1/2}, with omega coth(omega l) read as k cot(kl) for omega = ik and as 1/l for omega = 0; alpha_i(lambda) = omega coth(omega l) + m_i^Q, beta_j(lambda) = omega coth(omega l) - m_j^U, A = diag(alpha_i), B = diag(beta_j); W is the set of lambda > 0 with lambda^2 < m^2 + pi^2/l^2 for every bulk mass m of the system.

**Statement.**

1. For lambda in W, lambda is an eigenvalue of D_X iff det(lambda^2 - A X B X^dagger) = 0, with multiplicity dim ker(lambda^2 - A X B X^dagger).
2. alpha_i(0) = 2m/(1 - e^{-2ml}) with m = m_i^Q equals f_{Q_i}^2, the squared value at x = l of the normalized zero mode e^{mx}; likewise beta_j(0) = 2m/(e^{2ml} - 1) = f_{U_j}^2. In terms of c, f^2 = phi(c)^2/l with phi(c)^2 = 2c/(e^{2c} - 1) and phi(0) = 1.
3. On its own window 0 < lambda^2 < m^2 + pi^2/l^2, each alpha_i (and each beta_j) is strictly decreasing and concave in lambda^2, positive at 0 and tending to -infinity at the edge, so it vanishes exactly once, at the lowest positive eigenvalue Lambda_i^Q (respectively Lambda_j^U) of the single-field type-(c) problem. On the common window W it is still decreasing and concave but may stay positive: l = 1, M_Q = diag(0, 4) gives alpha_2 > 0 on all of W = (0, pi).
4. (Example 12.5) For N_Q = N_U = 1 and zero bulk mass, tan^2(lambda l) = |X|^2, and with theta = arctan|X| the positive spectrum is theta/l, (n pi - theta)/l and (n pi + theta)/l for n >= 1. At X = 0 zero has multiplicity two and the positive eigenvalues n pi/l have multiplicity two; theta = pi/2 is reached only as the limit |X| -> infinity, where each field becomes type (c) and the spectrum tends to two copies of (r - 1/2) pi/l. The light pair theta/l interpolates between the chiral zero modes of types (a) and (b) and the Connes-Lott mass pi/(2l) of lemma 05, with D acting as (theta/l) sigma_1 on a Gamma-graded two-dimensional space.

**Proof.** Lemma 12, Theorem 12.4 and Example 12.5; the proofs are there. Explicit solutions on each field and elimination give lambda^2 c = X B X^dagger A c, and the kernels of lambda^2 - C A and lambda^2 - A C have equal dimension for lambda != 0; monotonicity and concavity follow from x coth x = 1 + sum_{n >= 1} 2x^2/(x^2 + n^2 pi^2).

**What it leaves open.** The light spectrum and the towerless limit (12_light_spectrum_towerless_limit.md). Along the interpolation the index is constant and the symmetry changes (12_boundary_yukawa_index.md).
